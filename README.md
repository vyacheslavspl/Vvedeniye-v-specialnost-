## Работа с ветками и Pull Request

Цель практической работы — освоить работу с ветками Git
и Pull Request.

В рамках работы создана ветка `feature/greeting`,
внесены изменения в README.md, выполнен коммит
и создан Pull Request.

Изменения успешно объединены с основной веткой `main`.
Временная ветка удалена локально и на GitHub.
